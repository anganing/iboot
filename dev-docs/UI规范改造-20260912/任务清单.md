# UI 规范改造任务清单（2026-09-12）

本清单是 `dev-docs/后台UI开发规范.md` 第 3.3/3.2/6.0 节新规则落到存量代码的执行依据。
范围只覆盖 `mdm` / `wms` / `mes` / `aps` 四个模块，`bpm` / `system` / `infra` / `hrm` 不在本轮。

## 档位定义（操作列宽度）

可见按钮位数 = 固定展示的按钮数 + 「更多」下拉按钮本身算 1 位。

| 按钮位数 | 操作列 width |
| --- | --- |
| 1 | 100 |
| 2 | 160 |
| 3 | 220 |
| 4 | 280 |
| 5 | 340（需评审） |

固定动作超过 4 个必须把低频动作挪进 `dropDownActions`。上限 5 位（4 固定 + 更多）。
