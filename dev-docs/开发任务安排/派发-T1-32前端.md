## 任务二：修 `RouteOpDO` 的包名与目录错位

这是你上一轮自己报出来的问题，现在顺手修掉。

**事实**（我已核实）：

- 文件物理路径：`iboot-module-mdm\src\main\java\com\iboot\pf\module\mdm\dal\dataobject\route\RouteOpDO.java`
- 它的 package 声明：`package com.iboot.pf.module.mdm.dal.dataobject.routeop;`
- 同目录的 `RouteDO.java` 声明的是 `...dataobject.route`（一致）

所以 `RouteOpDO` 是全项目唯一一个包名与目录不匹配的类。能编译只是因为 Maven 把源文件显式喂给 javac，javac 对这种错位是容忍的，但 IDE 会警告，将来重构容易出错。

**怎么修：把文件移到与 package 声明一致的目录，不要改 package 声明。**

```
从：iboot-module-mdm\src\main\java\com\iboot\pf\module\mdm\dal\dataobject\route\RouteOpDO.java
到：iboot-module-mdm\src\main\java\com\iboot\pf\module\mdm\dal\dataobject\routeop\RouteOpDO.java
```

`routeop` 目录不存在，要新建。

**为什么是移文件而不是改 package**：我 grep 了全部引用，四处 import 的都是 `...dal.dataobject.routeop.RouteOpDO`（`RouteApiImpl`、`RouteController`、`RouteSaveReqVO`、`RouteOpMapper`），而 MyBatis XML 里**零引用**。所以移目录之后**一行 import 都不用改**；反过来改 package 声明要动那四处。

移完确认：`route\` 目录下只剩 `RouteDO.java`，`routeop\` 目录下只有 `RouteOpDO.java`，文件内容一个字不变。
