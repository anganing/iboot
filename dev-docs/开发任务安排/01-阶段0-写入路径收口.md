# 01 阶段 0 写入路径收口

- 版本：v1.0.0
- 目标：把 CRUD 界面从库存与工单的写入路径上撤下来，建立命令幂等载体。**不做这一步，后面全是白干。**
- 依据：`dev-docs/业务流程/03-WMS仓储库存流程.md` 全文，`04-MES生产执行流程.md` 的"一句话铁律"
- 任务数：20
- 完成标志：`rg` 搜不到任何 Controller 经 codegen Service 改库存余额或工单状态；每个领域动作都有幂等键；WMS 现有 21 个测试类全绿

## 阶段背景

WMS 是"先 codegen 生成 CRUD、再补领域层"的产物，18 张表有两套 DO 与两套 Service。领域层（过账、预留、冻结、四类单据）已完成且有测试，但 **Controller 全部注入的是 codegen Service**，界面上的每笔出入库都不改余额。

收口不是删掉一套。codegen 侧的 `selectPage` 与 Mapper XML 的 JOIN 查询有展示价值，保留；写入型方法删除，Controller 的写入端点转调领域 Service。
