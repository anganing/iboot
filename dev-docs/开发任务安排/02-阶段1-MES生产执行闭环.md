# 02 阶段 1 MES 生产执行闭环

- 版本：v1.0.0
- 目标：一张工单从 `DRAFT` 走到 `CLOSED` 全程只用动作端点，`mes_wip_txn` 有完整轨迹，库存三段（预留、出库过账、完工入库）账实一致且可用量无虚占。
- 依据：`dev-docs/业务流程/04-MES生产执行流程.md` 全文，`08-跨模块协作与端到端时序.md` 的"链路二"
- 任务数：31
- 前置：阶段 0 全部 18 个任务审查通过

## 阶段背景

MES 的表结构、枚举、CRUD 已全部就绪，缺的是动作层：135 个 Controller 端点全是 CRUD，`MesApiServiceImpl` 是空类，7 个门面抛 `UnsupportedOperationException`，`mes_wip_txn` 生产代码从未写入。

本阶段建的是"动作 → 状态机 → 推进链 → 库存联动"这条骨架。骨架建好后，阶段 2 的质量门禁才有地方挂。

## 并行组

| 组 | 任务 | 说明 |
| --- | --- | --- |
| A | T1-01 T1-02 T1-03 T1-04 T1-05 T1-06 | 基础设施，无依赖，组内并行 |
| B | T1-07 T1-08 T1-09 T1-10 T1-11 T1-12 T1-13 T1-14 T1-15 T1-16 T1-17 | 领域动作，依赖 A，组内有少量串行（见各任务） |
| C | T1-18 T1-19 T1-20 | 门面委托，依赖 B |
| D | T1-21 T1-22 T1-23 T1-24 T1-25 | 动作端点，依赖 C |
| E | T1-26 T1-27 T1-28 T1-29 T1-30 T1-31 | 前端，依赖 D |

## 统一约定

本阶段所有领域动作遵守：

| 约定 | 说明 |
| --- | --- |
| 幂等 | 走 `MesCommandService`（T0-02 已建），键格式见 `08` 的幂等键全表 |
| 状态校验 | 调对应状态机的 `next(current, action)`，非法迁移由状态机抛错 |
| 在制流水 | 每次状态变更调 `MesWipTxnRecorder`（T1-06 建），不在各动作里手写 DO |
| 事务 | 动作方法加 `@Transactional(rollbackFor = Exception.class)`，跨模块调用在同一事务内 |
| 跨模块 | 只走 `api` 门面，禁止跨库 JOIN，批量取数 |
| 乐观锁 | 推进 `mes_op_task` / `mes_prod_order` / `mes_work_order` 时带 `version` 条件 |
