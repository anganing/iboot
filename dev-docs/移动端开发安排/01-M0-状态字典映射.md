# M0 状态字典映射工具

- 依赖：无
- 独占文件：`iboot-ui/iboot-mobile/src/utils/dict.ts`（**仅本任务可写**）
- 依据：`dev-docs/开发任务安排/../CLAUDE.md` 红线「代码/枚举值列必须用字典或 formatter 映射成中文，不允许直接展示 `CRITICAL` 这类原始值」

## 做什么

新建 `src/utils/dict.ts`，把后端返回的枚举原始值映射成中文。**字典值已从 `system_dict_data` 实测取到，直接写死在前端常量里**——移动端不引字典接口，省一次请求。

### 必须覆盖的三张字典

| PENDING | 待排产 |

`wms_quality_status`（4 值）：

`wms_stock_scope`（2 值）：

| 值 | 中文 |

### 接口设计

至少导出：

```ts
/** 按字典类型取标签；查不到时回落原值（不要回落空串，否则页面看不出是哪个值出的问题） */
export function dictLabel(dictType: string, value?: string | number | null): string

/** 工序任务状态标签（快捷方式，列表高频用） */
export function opTaskStatusLabel(value?: string | null): string

/** 工序任务状态对应的展示色（用于 wd-tag 的 type 或自定义 class） */
export function opTaskStatusType(value?: string | null): string
```

色值建议（与项目主题 `--wot-color-theme: #1c64fd` 协调，参考 `notify/index.vue` 已有的绿色/橙色系）：
- 进行中（RUNNING / QC_WAITING）→ 主题蓝
- 完成（DONE）→ 绿 `#16a36a`
- 异常（PAUSED / HOLD / CANCELLED）→ 灰或橙
- 待办（PENDING / READY）→ 默认灰

### 约束

- 用 `interface` / `type` 定义字典结构，**禁止 `any`**
- 不引第三方依赖
- 该文件会被 M1（库存查询，用 `wms_quality_status` / `wms_stock_scope`）、M3（任务列表，用 `mes_op_task_status`）依赖，**接口命名要稳，改动会波及两个任务**
